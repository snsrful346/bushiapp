# bushiapp — 合気道部の出席・稽古記録アプリ

合気道部の出席管理と稽古記録を扱うWebアプリケーションです。現在は、画面構成と入力フォーム、データモデルを作成した開発途中の段階です。

## 開発背景

合気道部ではExcelで出席管理を行っており、毎回の入力、出席者の確認、出席回数の集計に手間を感じていました。この負担を減らすため、出席管理を行うWebアプリの開発を始めました。

稽古日と出席者を登録し、出席記録の一覧表示や部員ごとの出席回数の自動集計ができる仕組みを目指しています。将来的には、稽古内容も記録し、活動の振り返りに役立てたいと考えています。

## 担当範囲

画面構成、入力フォーム、Flaskによる画面のルーティング、データモデルの定義を主に自分で実装しました。

## 構成

```text
bushiapp/
├── app.py                    # 画面のルーティング・データモデル
├── templates/
│   ├── base.html             # 共通HTMLテンプレート
│   ├── index.html            # トップ画面
│   ├── record.html           # 稽古記録の入力画面
│   ├── records.html          # 一覧画面のひな形
│   └── analytics.html        # 集計画面のひな形
└── LICENSE
```

共通部分を `base.html` にまとめ、各画面が継承する構成にしています。

## ローカルでの起動手順（Windows／PowerShell）

PythonとGitが導入された環境で、以下を実行します。

```powershell
git clone https://github.com/snsrful346/bushiapp.git
cd bushiapp
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install Flask Flask-SQLAlchemy
.\.venv\Scripts\python.exe app.py
```

起動後、ブラウザで `http://127.0.0.1:5000` を開きます。

この手順はコードから整理したもので、動作確認は未実施です。依存ライブラリのバージョン指定も今後追加します。現在の起動設定はデバッグが有効なため、ローカル開発用です。
